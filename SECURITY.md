# Security Policy

This project is intended for authorized defensive monitoring, lab simulation, and portfolio demonstration.

## Supported Use

- Normalize and analyze telemetry you are authorized to collect.
- Run synthetic events and sample Zeek or Suricata JSON in a lab.
- Use local indicators and disabled-by-default external provider interfaces.

## Out Of Scope

- Exploitation, malware execution, persistence, credential attacks, evasion, or unauthorized scanning.
- Autonomous firewall, endpoint, or network blocking changes.
- Handling production secrets or regulated datasets inside this repository.

## Reporting Issues

Open an issue or contact the repository owner with:

- A concise description.
- Affected files or endpoints.
- Reproduction steps using safe sample data.
- Any suggested mitigation.

Never include secrets, live customer telemetry, PCAPs, or private indicators in public reports.
